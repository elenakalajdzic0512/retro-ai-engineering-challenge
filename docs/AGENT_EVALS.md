## 2026-10-06 — W05 Checkpoint 3: Bounded Three-State Agent Orchestrator

**Observed implementation**: The provider-neutral application runs the fixed `NEED_SNAPSHOT → NEED_EVALUATION → NEED_FINAL` sequence, with no open-ended tool loop. The first state accepts only `get_tactical_snapshot({})`; the second accepts only `evaluate_tactical_strategy` with the four validated candidate fields; the third accepts only a final plan. A rejected candidate stops after tool 2. Early finals, out-of-order actions and a third tool stop without executing an invalid tool. Successful runs use three logical steps and two tools; provider attempts are capped at four. One global transient retry for `provider_timeout`, `provider_unavailable` or `rate_limited` stays in the same state and uses a fixed 100 ms backoff.

**Time and authority bounds**: Each provider attempt has a real abortable timeout of `min(5000 ms, remaining deadline)`. One monotonic 22-second deadline covers provider work, backoff, tools, validation and orchestration overhead. Synchronous local tool work has a 100 ms elapsed budget. Caller cancellation stops progression without a partial plan. A request-scoped canonical state/tool/argument key provides repeat protection; a narrow helper test covers `repeated_action` because ordinary duplicates are stopped first by the strict state order. Tool execution uses the Checkpoint 2 validated boundary and stored results are copied before forwarding.

**Final result**: The existing final-plan validator requires exact equality with the accepted candidate, one to three actions, approved fact references and both evidence sources. The application resolves references from this run's validated snapshot and evaluation results and returns only `{plan, evidence}`. Values remain strings, finite integers or booleans; model-authored values are rejected. The normalized model plan and materialized public success body are each limited to 4096 serialized UTF-8 bytes without truncation. A fixed error-code/message map keeps provider exceptions and raw output out of public failures.

**Automated evidence**: Checkpoint 3 added **25 orchestration tests** and **one T017 contract test** for an oversized normalized final plan.
